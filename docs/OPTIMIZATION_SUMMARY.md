## 优化方法总结

### 提高分数的关键策略：

1. **增加采样步数 (nfe_step)**
   - 从 100 提升到 150
   - 更高的步数 = 更高质量的生成，但推理时间更长
   - 建议范围：100-200

2. **提高引导强度 (cfg_strength)**
   - 从 2.5 提升到 3.0
   - 更高的引导强度 = 更忠实于参考音频
   - 建议范围：2.0-3.5

3. **优化评估指标处理**
   - 确保使用正确的采样率
   - 正确提取所有评估指标的分数
   - 处理不同格式的返回值

4. **参考音频选择**
   - 使用高质量的参考音频（000018.wav）
   - 确保参考音频清晰、无噪声
